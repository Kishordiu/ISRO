# ISRO Web Experience

> **A frontend exploration inspired by India's space-technology ecosystem.**

This repository contains a web interface experiment built around ISRO-themed information and presentation. It is an independent software project and is not an official ISRO repository.

## Focus
- Space-themed visual presentation
- Responsive web interface
- Interactive information layout
- Modern frontend implementation

## Stack
React · TypeScript · Vite · Tailwind CSS

## Run locally
~~~bash
npm install
npm run dev
~~~
