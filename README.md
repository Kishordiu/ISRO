> **SPACE / INFORMATION DESIGN.**

## THE PREMISE

An independent frontend exploration inspired by India's space-technology ecosystem, built as an exercise in information hierarchy, visual storytelling and responsive interaction.

## THE EXPERIENCE

**Make complex systems legible.**  
**Use visual rhythm to guide attention.**  
**Respect the boundary between inspiration and official representation.**

## THE SYSTEM

A React/TypeScript frontend shapes a space-themed information experience. This repository is independent and is not an official ISRO product or endorsed interface.

## THE STACK

React · TypeScript · Vite · Tailwind CSS

## RUN

```bash
npm install
npm run dev
```

## PROJECT STATE

**Independent frontend exploration**

Implemented behaviour is documented separately from future integrations so the project story stays honest as the product evolves.
